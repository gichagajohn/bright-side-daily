Drop royalty-free audio tracks in this folder.

Any .mp3, .m4a, .wav, .ogg, .opus or .flac file here is picked at random and
looped under the Reel, replacing the generated ambient pad.

Rules that keep the account safe:
  - only tracks you actually have the right to use commercially
  - no vocals over a quote card (the words fight the text)
  - calm, slow instrumentals work best for encouragement content

Instagram's own music library cannot be attached through the API, so the
audio has to be baked into the file before upload.

Leave this folder empty and the generator synthesises its own pad, which is
royalty-free by definition because it is just generated tones.

Controls:
  IG_REEL_AUDIO=auto | pad | file | off     (default auto)
  IG_REEL_VOLUME=0.6                        (0.0 - 1.0)
